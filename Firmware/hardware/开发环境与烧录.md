## 1. 已知硬件与待确认项

| 项目 | 内容 | 来源 |

## 2. 安装 Arduino IDE

1. 从 [Arduino 官网下载页](https://www.arduino.cc/en/software) 下载 Arduino IDE 2.x 的 Windows 安装包并安装。记录实际版本号（帮助 → 关于）。
2. 安装时若提示安装 USB 驱动，可以接受。

## 3. 安装 esp32 板卡包

依据：[arduino-esp32 官方安装说明](https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html)（[源文件](https://github.com/espressif/arduino-esp32/blob/master/docs/en/installing.rst)）。

1. 文件 → 首选项 → “其他开发板管理器地址”填入下面之一：
   - 国际稳定版：`https://espressif.github.io/arduino-esp32/package_esp32_index.json`
   - 国内用户按官方说明可改用极狐镜像：`https://jihulab.com/esp-mirror/espressif/arduino-esp32/-/raw/gh-pages/package_esp32_index_cn.json`
2. 工具 → 开发板 → 开发板管理器，搜索 `esp32`，安装 Espressif Systems 的 **esp32** 包。使用镜像时，官方说明要求选带 `-cn` 后缀的版本，并手动更新（自动更新会指向没有 `-cn` 的包，从而下载失败）。
3. 记录实际安装的板卡包版本号，填入[串口记录模板](../../Tests/串口记录模板.md)。团队成员使用同一版本，升级须记录。

## 4. 开发板选项

板型先统一选通用的 **ESP32S3 Dev Module**。确认板子品牌之后，若板卡包里有对应专用板型，再改并记录。选项名称取自 [arduino-esp32 boards.txt](https://github.com/espressif/arduino-esp32/blob/master/boards.txt) 中 `esp32s3` 菜单项。

| 选项 | N16R8 | N8R8 | 说明 |
|---|---|---|---|
| Flash Size | 16MB (128Mb) | 8MB (64Mb) | 与模组 Flash 容量一致 |
| PSRAM | OPI PSRAM | OPI PSRAM | R8 为八线 PSRAM；选 QSPI 会导致 PSRAM 不可用或启动异常 |
| Flash Mode | QIO 80MHz | QIO 80MHz | N16R8/N8R8 的 Flash 为四线；若启动失败再试 DIO 80MHz 并记录 |
| Partition Scheme | 例如 `16M Flash (3MB APP/9.9MB FATFS)` | 例如 `8M with spiffs (3MB APP/1.5MB SPIFFS)` | 是否需要本地文件系统存日志，由 B 的缓存方案决定，**待确认** |
| USB Mode | Hardware CDC and JTAG | 同左 | 使用原生 USB 口时 |
| USB CDC On Boot | 见下 | 见下 | 决定 `Serial` 走哪个口 |
| Upload Mode | UART0 / Hardware CDC | 同左 | 默认值 |

USB CDC On Boot 必须写进记录，否则串口监视器可能没有输出：

- 用**原生 USB 口**（GPIO19/20）连电脑：设为 **Enabled**，`Serial` 输出到该 USB 口。
- 用**USB 转串口芯片那个口**（UART0）连电脑：设为 **Disabled**，`Serial` 输出到 UART0。
- 板子只有一个口且不确定类型时：插上后看设备管理器里的名称（见下一节）再定。

## 5. 驱动与端口识别

依据：[ESP-IDF 与 ESP32-S3 建立串口连接（中文）](https://docs.espressif.com/projects/esp-idf/zh_CN/latest/esp32s3/get-started/establish-serial-connection.html)。

1. 用能传数据的 USB 线。有的线只能充电。
2. 打开设备管理器 → “端口 (COM 和 LPT)”：
   - 原生 USB：Windows 10/11 一般自带驱动，显示为“USB 串行设备 (COMx)”。
   - CH343/CH340：名称里有 `CH34x`。没有端口时，CH343 安装 [沁恒 CH343 驱动](https://www.wch.cn/downloads/CH343SER_EXE.html)，CH340 安装 [CH341SER](https://www.wch.cn/downloads/CH341SER_EXE.html)。
   - CP210x：安装 [Silicon Labs CP210x 驱动](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers)。
   - 板上实际是哪种芯片：**待确认**（看板背面芯片丝印）。
3. 给每块板贴标签，例如 S3-16-1、S3-16-2、S3-8-1、S3-8-2。记录“标签—COM 号—USB 口类型”。换 USB 口后 COM 号可能变化，每次实验重新记录。

## 6. 烧录与串口监视

1. 工具 → 端口，选择对应 COMx，并按上一节设好开发板选项。
2. 先烧录 Arduino 自带示例（文件 → 示例 → 01.Basics → Blink，或任一串口打印示例）验证工具链。这一步不写项目代码。
3. 点“上传”。若停在 `Connecting...`：按住 **BOOT**，点一下 **RST/EN**，松开 BOOT，进入下载模式后再上传。完成后按 RST 运行。原生 USB 口在下载模式下 COM 号可能变化，需要重新选端口。
4. 打开工具 → 串口监视器。波特率与程序一致（示例常用 115200），把行尾设置记下来。这里的波特率是电脑和 ESP32 之间的 `Serial`，不是 LoRa 模块的 9600 8N1。
5. 保存上传日志（输出窗口全文）和串口输出前 30 秒，按[串口记录模板](../../Tests/串口记录模板.md)填写。
6. 4 块板逐一完成。任何一块失败，都记录现象和处理方法。

## 7. 常见问题

遇到之后再补。下表的处理办法都还没有在这批板上验证。

| 现象 | 可能原因 | 处理 | 是否已验证 |
|---|---|---|---|
| 上传后串口无输出 | USB CDC On Boot 与所用 USB 口不匹配 | 按第 4 节调整后重新上传 | 待验证 |
| 启动反复重启，或 PSRAM 报错 | PSRAM 选成 QSPI，或 Flash 设置不符 | 改 OPI PSRAM，核对 Flash Size | 待验证 |
| 设备管理器无端口 | 充电线，或缺驱动 | 换数据线，安装对应驱动 | 待验证 |
