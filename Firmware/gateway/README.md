# 网关板端

A 负责板端收发与串口输出，B 统一消息和日志，D 在 [Host](../../Host/README.md) 接入电脑端。这里尚无已验证固件。

交付时补实际板型、引脚、依赖版本、构建/烧录命令、串口参数和样例日志。按[统一协议](../../docs/protocol/README.md)处理半帧、错误长度和重连。网关日志采集不能暗中替代断链实验中的无线业务传输。
