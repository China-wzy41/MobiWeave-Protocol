# 节点

近期是无屏节点。整条手机坐标 → 低功耗蓝牙（BLE）→ 本机节点 → LoRa → 队友节点 → 队友手机显示作为整体还没有实现，也没有整段验证。实验台上的 ESP↔LoRa 与两节点无线通信已在记录条件内做过；确认、重试、去重、转发和多跳没有验收。BLE、队友手机显示和整段集成还没做。断连后的保存和携带只做轻量验证。当前目标不是五节点，也不是带屏终端。
