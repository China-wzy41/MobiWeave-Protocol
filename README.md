# MobiWeave-Protocol
面向灾害通信孤岛的移动节点通信重建与自适应调度系统。

## 项目简介
本项目使用低成本LoRa节点构建自组网。
当灾害造成通信区域相互隔离时，系统通过移动节点携带和转发数据，
并根据消息优先级、节点电量、链路质量和移动距离选择合适的中继位置。

## 核心功能
- LoRa多跳通信
- 通信孤岛识别
- 移动节点调度
- 延迟容忍网络
- GPS位置记录
- RSSI信号覆盖可视化
- 手机和移动机器人接口
