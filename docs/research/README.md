# 研究范围

当前验证轻量延迟容忍：有上限的缓存、消息存活时间，以及断连后的保存、携带和转发。主场景是户外徒步的位置和短文字。日志校验、统计、回放和实验设计由 C（ygh）负责。

数字孪生不在当前交付里，不排成后期承诺，研究上也不永久取消。徒步场景稳定后，偏远巡检和高校实验可以作为候选。

正结果和负结果都留下。模拟不能代替实物。阅读起点是 [RFC 4838](https://www.rfc-editor.org/rfc/rfc4838.html)。本项目不据此自称完整兼容某一版协议标准。

方向见 [长期计划](../planning/长期计划.md)，验证方法见 [怎么验证](../method/README.md)。
