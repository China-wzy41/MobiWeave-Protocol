## 以后必须注意

1. **LoRa独立供电。** 本次YD板的5V排针带模块时明显掉压，以后这套设备不从ESP32的5V或3V3引脚给LoRa取电，继续使用PJ15或稳定的独立5V电源；两路电源的正极不要相连。
2. **必须共地。** ESP32 GND、LoRa GND和LoRa电源负极接在一起，否则UART没有共同的电压参考，可能收不到数据或通信不稳定。
3. **进入AT要注意结束符。** 本次实测发送三个加号并带CR、LF才得到Entry AT；串口工具直接发送时选“NL和CR”，后续AT命令也带回车换行。不要再按无结束符作为本次设备的默认操作。
4. **使用V2菜单程序时按菜单操作。** 先发数字4进入AT，再发2验证OK、发3读配置。菜单4已明确发送三个加号加CR、LF；仅更改监视器的结束符，不能改变旧程序菜单1只发三个加号的内容。已经进入AT后不要反复发送进入命令。
5. **串口和接线保持一致。** 电脑端115200；LoRa端9600、8N1；模块TXD→ESP18，模块RXD→ESP17。PJ15只供电时，其TX/RX都断开，避免与ESP同时驱动信号线。5V只用于供电，不能接到UART信号脚。
6. **避开可疑母座供电路径。** 当天通过该母座时曾出现严重掉压，绕过后恢复；继续用已验证的直连方式，但不把原因写死为虚焊。
