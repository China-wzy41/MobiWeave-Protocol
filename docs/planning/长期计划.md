# 长期计划

方向在 **2026-11-23**（北京时间）更新。2026-10-30 的记录里，团队曾选择方案 B。从这一天起，现行方案是无屏节点，不再把带屏独立终端当作当前方向。

## 目标

面向户外徒步。没有公网时，手机取得卫星坐标，经低功耗蓝牙（BLE）交给无屏的 ESP32 + LoRa 节点，再传给有效无线范围内、带着兼容节点的队友。队友用自己的手机查看。优先做位置共享、短文字、离线地图上的集合点标注。设备要小、轻、能随身带。

整条链路作为整体还没有实现，也没有整段验证，并仍须实地测试：

手机取得坐标 → BLE → 本机无屏节点 → LoRa → 队友节点 → 队友手机显示

已有的 ESP 与 LoRa 实验台通信，以及两节点之间的无线通信，在留下的记录条件内已经做过。2026-11-17 的接线与串口 bring-up 保留。BLE、队友手机显示，以及把各段接成这条整段链路，还没做。没有蜂窝网络时，手机仍可能取得卫星坐标；权限、冷启动和天空遮挡还没有在本项目里测试。确认、重试、去重、转发和多跳没有验收。

## 当前阶段

- 当前交付只做户外徒步。徒步场景稳定之后，偏远巡检和高校实验可以作为候选，不排进当前交付，也不另做两套产品。
- 节点不带屏幕。手机负责定位、输入和显示。节点用 BLE 接收，再用 LoRa 发出。队友用手机连接自己的兼容节点查看。
- 功能顺序：共享位置、短文字、在离线地图上标注集合点，同时把体积和重量放进结构约束。前三项先打通。体积、重量、连接距离等实测后再定，不先写死数字。
- 地图在手机上预先下载，不走 LoRa。LoRa 只传位置、文字、集合点这类必要信息。
- 近期不采购独立 GNSS 模块，也不采购随身供电。已到货的 GNSS 模块留着，节点保留以后能接的接口。开发台上 2026-11-17 用过的是电脑 USB，见下面的接线记录。
- 数字孪生不放入当前交付，也不据此排成后期承诺。研究上不把它永久取消。
- 轻量延迟容忍只做有界缓存、存活时间和存储—携带—转发的验证，不做成大平台。日志校验、统计、回放和实验设计由 C（ygh）负责。
- 任何户外或外场使用之前，先核对适用的工信部规定：频段、设备类别和用途、设备条件、带宽和发射时长、天线，以及型号核准或豁免是否适用，然后再配置 LoRa。这是前提，不是以后再办的事项。系统还没有完成这项核对，文档不写已经合规。降低功率、433 MHz 遥控类规定和 22 dBm，都不能自动使徒步中的文字、位置或多跳使用合法。

## 下一步

1. 把整条链路做出来并实地测试：手机取得坐标 → BLE → 本机无屏节点 → LoRa → 队友节点 → 队友手机显示。实验台上的两节点无线通信已经在记录过的条件内做过。BLE、队友手机显示，以及把它们和 LoRa 接成整段，还没做，也还没有实地测试。
2. 做出能试用的位置共享和短文字。日志按已冻结的 v1 记录。
3. 手机上的离线地图能标注集合点，集合点坐标可以沿链路共享。地图瓦片只留在手机本地。
4. 收束结构方案，做出能随身带的样机。体积、重量和连接距离以实测为准。
5. v1 分成四件各自记账的事：
   - 格式已经冻结。工作基线是 B（hsr）工作分支 `Yanis0118-patch-1` 尖端 `ca128e3d88589a5ef82af96bcf9f2ea97a2768ec` 上的现有日志：`docs/protocol/log-v1.md`、`docs/protocol/examples/log-v1-sim.jsonl`、`docs/protocol/examples/log-v1-extra.jsonl`，以及同提交上的 `tools/mwlog_check.py`。这些文件不在 `main`。文件正文仍写着候选、尚未冻结，那是这次决定之前的文字。
   - 团队计划在 2026-11-23 晚间另行开启一个把 v1 送进 `main` 的拉取请求。本清理不打开那个请求。写入本文件时，它还没有作为已打开或已合并的请求被记录。
   - 合入 `main` 是下一步，本次不合并 `Yanis0118-patch-1`。
   - 确认、重试、去重、转发、多跳各自还要证据。格式冻结不包含这五项。
6. 任何外场之前先做完无线电核对，再按核对结果配置 LoRa。核对没完成，不安排外场。

`main` 上的 `docs/protocol/protocol-v1.md` 是更早的讨论稿。同名的冻结工作文本在上述分支，不在 `main`。

## 验收边界

- v1 冻结只表示采用上述分支上的日志格式作为实现和记录的基线。它不等于已经合入 `main`。
- 确认、重试、去重、转发、多跳逐项实测。有可以复查的记录才算通过。没有证据就保持未验收。
- 当前最小功能的验收目标：至少两名队员，各带手机和兼容节点，在当场有效连接范围内，一方的位置和一条短文字能在另一方手机上显示；一方标注的集合点能在另一方的离线地图上看到。测试条件、距离和失败情况都要留下记录。这是目标，不是已经做到的结果。
- 体积、重量、连接距离以样机实测为准。目标值待定。不用参数表或主观感受代替实测。
- 无线电核对是外场前提。文档不写已经合规。
- 现有问卷只有少量样本，不能推出市场或销量结论。当前验收不包含市场验证。
- 下列各项不在当前验收里：去中心化多终端、独立 GNSS、把数字孪生做成交付物、偏远巡检、高校实验。数字孪生不因此被永久取消。
