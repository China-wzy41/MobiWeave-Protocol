## 一次软件演示怎样算闭环

B 的格式 → C 生成正常及故障事件 → D 读取并显示节点与消息 → D 保存日志 → C 核对发送、唯一接收、缺号和重复 → 另一成员按说明复现。

A 的实物串口记录若已完成可加入演示；没有板时显示“模拟通过、板端待验”。LoRa 无线不属于本月软件验收的替代证据。没有真实无线输入时，RSSI/SNR 写未知或明确模拟值。

## 边界与交付约定

- B 负责格式版本。修改字段前通知 A/C/D，样例和解析同步调整；禁止各自创建同名不同含义的字段。
- C 负责模拟、校准、实验和统计；D 负责接入、界面、保存和回放操作。D 使用 C 的结果，不在界面内另算一套不一致指标。
- A 负责接线与板端，D 负责电脑串口。LoRa 等待不阻塞文件回放、界面、需求与研究工作。
- E 记录预算上限、已有/新增/借用/延期清单；未知报价、到货日和赛事日期写待确认。访谈由团队开展，这份计划不代表已联系任何人。
- 每份交付附启动步骤、版本、输入、预期输出和已知限制。没有可运行程序时写“待实现”，不放虚假的成功截图。
- 真实访谈只提交匿名摘要；不公开联系方式、精确个人轨迹等原始信息。
